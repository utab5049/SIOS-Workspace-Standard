# CONTRIBUTING

Contributions follow AERA-001D (Artifact Organization) and AERA-001F (Workspace Evolution). Before proposing a change:
1. Classify it (Compatible / Minor / Major / Breaking) per AERA-001F §5.
2. If it touches Evidence or Framework content, apply ERS-001 §6.1 (Claim Granularity Principle) — added 2026-08 specifically because of a real, observed failure to do this.
3. Independent review is not optional. See 02-Research/Audit/ for what happens when it's skipped.
