## 1. Purpose

CIR-001 is the authoritative index of every SRC-XXXXXX source instance registered across all SIOS research corpora, satisfying MAI-001 §3's traceability principle without requiring individual sources to be top-level MAI-001 rows (per DECISION-MAI001-OPTION-B.md).

## 2. Schema

| Field | Description |
|---|---|
| Source ID | SRC-XXXXXX |
| Title | Full title |
| Corpus | Corpus ID (e.g., CORPUS-001) |
| Domain | COR-001 research domain (A/B/C/D) |
| Status | Accepted / Conditional / Rejected |
| Full-Text Status | Full-text extracted / Abstract-only / Not attempted |
| Detail Location | File containing full source registration record |
