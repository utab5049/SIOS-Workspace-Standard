## 8. Known Limitations (Documented, Not Hidden)

1. **Tier 1/2 databases not reached.** Scopus/Web of Science require credentials not available in this environment (per SRE-000001 §8, Limitation Statement — same limitation persists). OpenAlex, the intended open fallback, was rate-limited at execution time.
2. **No automated Runner normalization.** ARR-001C (OpenAlex Provider) could not run because the API call itself failed before reaching the normalizer. Records below were mapped manually to the canonical `Record` schema (ARR-001B §6.2) — this satisfies the *schema* contract but not the *automation* contract. This is a legitimate audit finding for AC-001 §7.3 (Operational Need) if it recurs.
3. **Single-domain concentration.** All 5 accepted sources fall under Domain C (Ontology Engineering). Domains A, B, D (per COR-001 §6) remain unrepresented in this batch — flagged as an open corpus-balance gap, not silently ignored (see companion balance-check note in SRC-CORPUS-001-ENTRIES.md §Balance Check).
4. **Retry exhaustion not exhaustive.** Only 4 retry attempts were made against OpenAlex within this session; a longer cool-down period was not tested. Re-attempting SRE-000001-A in a future session remains valid and preferred once rate limiting clears.
